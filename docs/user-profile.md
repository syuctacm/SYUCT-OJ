# 用户主页 API 与页面

## 接口

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/v1/users/:uid` | 公开用户资料 |

公开资料返回用户 ID、用户名、显示名、学号、头像、简介、注册/登录时间和提交/通过统计，不返回邮箱和密码字段。

## 前端

- `/user/:uid`：用户主页
- 登录后的导航栏用户名会链接到自己的主页
- 页面结构和类名对应 Hydro `user_detail.html` 的 `.profile-header`、`.profile-content` 和侧栏统计
