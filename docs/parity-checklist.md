# 前端视觉与交互对照清单

## 1. 原则

- 复用旧站 CSS、字体、图标和 DOM 结构。
- 不改变核心颜色、间距、圆角和交互习惯。
- 先对齐核心流程，再处理低频页面。
- 每个页面都要有旧站/新站截图和操作记录。

## 2. 页面优先级

### P0 核心闭环

- 登录 / 登出
- 首页
- 题目列表
- 题目详情
- 代码提交
- 提交记录列表
- 提交详情 / 实时判题状态
- 用户中心基础页

### P1 常用功能

- 比赛列表 / 详情
- 比赛题目列表
- 比赛榜单
- 训练列表 / 详情
- 作业列表 / 详情
- 用户资料 / 活跃日历
- 标签统计榜单

### P2 管理功能

- 题目编辑 / 配置 / 文件
- 比赛管理
- 训练管理
- 作业管理
- 域管理（删除，不迁移）
- 系统设置 / 用户管理

## 3. 交互检查

- 表单提交和错误提示
- 路由跳转和浏览器历史
- 分页、排序、筛选
- Markdown、KaTeX、代码高亮
- Monaco 编辑器
- 文件上传、下载、拖拽
- 实时 WebSocket 更新
- 比赛倒计时、榜单刷新
- 移动端布局
- 空状态、加载状态、403/404/500 页面

## 4. 自动化验证

- Playwright 登录和核心 E2E
- 关键页面截图对比
- API 契约测试
- 迁移后数据页面抽查
- 权限角色抽查

## 5. 已知差异记录

每次迁移页面时记录：

```text
页面：
旧站行为：
新站行为：
差异级别：
是否接受：
负责人：
后续处理：
```
