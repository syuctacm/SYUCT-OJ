# 前端视觉与交互对照清单

## 1. 原则

- 以 Hydro `ui-default` 模板和旧站实际输出的 HTML 为唯一结构来源，不自行设计近似页面。
- 复用旧站 CSS、字体、图标、类名和 DOM 层级。
- 旧插件样式必须从原站 HTML/源码原样移入 `web/src/legacy/`，不得凭截图手写近似 CSS。
- React 壳层只负责路由和浏览器生命周期，不在 `.main` 中额外包 `.row`；每个页面自己输出原模板的 `.row`。
- 路由必须同步原模板的 `data-page`、`data-layout` 和 `page--*` 类，页面级 CSS 才能生效。
- 截图只用于最后验收，不能代替源码对照。

## 2. 页面优先级

### P0 核心闭环

- 登录 / 登出
- 首页
- 题目列表
- 题目详情
- 代码提交
- 提交记录列表
- 提交详情 / 实时判题状态
- 用户中心基础页

### P1 常用功能

- 比赛列表 / 详情
- 比赛题目列表
- 比赛榜单
- 训练列表 / 详情
- 作业列表 / 详情
- 用户资料 / 活跃日历
- 标签统计榜单

### P2 管理功能

- 题目编辑 / 配置 / 文件
- 比赛管理
- 训练管理
- 作业管理
- 域管理（删除，不迁移）
- 系统设置 / 用户管理

## 3. 交互检查

- 表单提交和错误提示
- 路由跳转和浏览器历史
- 分页、排序、筛选
- Markdown、KaTeX、代码高亮
- Monaco 编辑器
- 文件上传、下载、拖拽
- 实时 WebSocket 更新
- 比赛倒计时、榜单刷新
- 移动端布局
- 空状态、加载状态、403/404/500 页面

## 4. 自动化验证

- Playwright 登录和核心 E2E
- 原模板结构、类名和关键计算样式核对
- 最后阶段再做关键页面截图回归
- API 契约测试
- 迁移后数据页面抽查
- 权限角色抽查
