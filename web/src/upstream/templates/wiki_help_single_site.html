提交与评测

在题库或比赛题目页选择语言并提交代码。系统会通过 HydroJudge 使用标准输入输出进行评测。

比赛和作业可能限制可用语言、提交时间和访问权限，请以页面提示为准。

评测状态

  • Accepted：通过
  • Wrong Answer：输出与标准答案不一致
  • Time Limit Exceeded：运行时间超限
  • Memory Limit Exceeded：内存超限
  • Runtime Error：运行错误
  • Compile Error：编译失败
  • System Error：评测系统错误，请在讨论区反馈

账号与使用

可以在账户设置中修改资料和密码，在安全设置中管理 TOTP、Passkey 和登录会话。

忘记密码可以通过登录页的找回密码入口重置。若仍有问题，请到讨论区反馈。
